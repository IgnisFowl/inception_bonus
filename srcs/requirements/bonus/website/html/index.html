Running Services

Eight Docker containers communicating over a private bridge network. Each service runs in its own isolated environment.

🔒

NGINX

Reverse proxy and TLS termination. Only entrypoint to the infrastructure via port 443 with TLSv1.2 / TLSv1.3.

mandatory · port 443
📝

WordPress + php-fpm

Full WordPress installation served via FastCGI on port 9000. Two users: an admin and an author.

mandatory · port 9000
🗄️

MariaDB

Relational database for WordPress. Data persists in a named Docker volume bound to the host filesystem.

mandatory · port 3306
⚡

Redis Cache

In-memory object cache for WordPress. Reduces DB queries with LRU eviction policy and 256 MB memory limit.

bonus · port 6379
📂

FTP (vsftpd)

Secure FTP server pointing to the WordPress files volume. Passive mode on ports 21000–21010.

bonus · port 21
🌐

Static Website

This very page! A portfolio / showcase site served by a dedicated nginx container on port 80.

bonus · port 80
🔍

Adminer

Lightweight database management UI. Connect directly to MariaDB through your browser on port 8080.

bonus · port 8080
🐳

Portainer

Container management dashboard. Monitor and control all running containers through a web UI on port 9000.

bonus · port 9000

About This Project

Inception is a 42 School system administration project. The goal is to build a complete Docker infrastructure from scratch — writing every Dockerfile manually, using no pre-built images, managing secrets securely, and connecting services through a private Docker network.

Every container runs its process as PID 1 with proper daemon handling (no tail -f, no sleep infinity) and restarts automatically on crash.
